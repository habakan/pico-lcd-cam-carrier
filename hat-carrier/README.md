# HAT carrier (KiCad draft, Rev E)

Waveshare 1.3inch LCD HAT、Pico 2 H、OV7675（Arducam B0070）を**はんだ付けせずに差すだけ**で組むためのキャリア基板の下書きです。コネクタ4つを実装済みで発注し、組む人は3枚の基板を差してねじを締めるだけにします。はんだ付けで組む [Rev D](../pico2h-carrier/README.md) とは別系統です。

GPIO の割り当ては `src/board_pins.h` と同じなので、ファームはそのまま動きます。

## ファイル

- `generate.py`: 下の4ファイルを書き出す。配線や配置を変えるときはこれを直して `python3 generate.py` を実行する。
- `hat_carrier.kicad_sch`: コネクタ単位の回路図。
- `HatCarrier.kicad_sym` / `sym-lib-table`: この設計用のシンボル。
- `hat_carrier.kicad_pcb`: 86 x 34 mm・四隅1 mm面取りの外形、M2.5固定穴3つ、部品とピン列の機械領域（Dwgs.User）。電気フットプリントは未配置。

## コネクタ

| Ref | 対象 | 面 | フットプリント |
|---|---|---|---|
| J1 | Pico 2 H 左列、物理ピン1–20 | B | 1x20 2.54 mm ピンソケット |
| J2 | Pico 2 H 右列、USB側から物理ピン40–21 | B | 1x20 2.54 mm ピンソケット |
| J3 | 1.3inch LCD HAT（Raspberry Pi 40ピン番号） | F | 2x20 2.54 mm ピンヘッダ（オス） |
| J4 | OV7675 / Arducam B0070 | B | 2x10 2.54 mm ピンソケット |
| J5 | Debug Probe UART RX/GND | F | 1x2 パッド。部品は載せない |

HAT 側の接続は Waveshare の回路図（`1.3inch-LCD-HAT-Schematic.pdf`）で確認しました。

| J3 ピン | HAT の信号 | ネット | Pico |
|---|---|---|---|
| 1, 17 | 3.3V | 3V3 | 物理36 |
| 13 | LCD RST | 3V3（起動時は SWRESET） | - |
| 18 | LCD BL | 3V3（HAT 上でも 10k でプルアップ済み） | - |
| 24 | LCD CS | GND（SPI mode 3） | - |
| 6, 9, 14, 20, 25, 30, 34, 39 | GND | GND | - |
| 23 / 19 / 22 | LCD CLK / DIN / DC | LCD_SCK / LCD_MOSI / LCD_DC | GP18 / GP19 / GP16 |
| 31 / 35 / 29 / 37 / 33 | 上 / 下 / 左 / 右 / 押し込み | BTN_UP / DOWN / LEFT / RIGHT / SELECT | GP13 / GP17 / GP20 / GP22 / GP26 |
| 40 / 38 / 36 | KEY1 / KEY2 / KEY3 | BTN_REJECT / BTN_B / BTN_C | GP27 / GP28 / GP1 |
| 2, 4 | 5V | **未接続** | - |

カメラの接続は Rev D と同じで、PEN を 3V3、PDN を GND に固定します。ボタンは押すと GND に落ちる作りで、プルアップは RP2350 の内部プルアップを使います。

## 配置

PCB 座標（前面から見た KiCad 座標、mm）。B 面部品は前面から見て左右反転して置きます。

| 部品 | 面 | 位置 | 向き |
|---|---|---|---|
| HAT | F | (10.5, 0.9)–(75.5, 31.1) | ソケットが上辺。左にジョイスティック、中央に LCD、右に KEY1–3 |
| J3 | F | 中心 (43, 4.4) | 1番ピンは左端の下の列 (18.87, 5.67) |
| Pico 2 H | B | (0.75, 12.25)–(51.75, 33.25) | 部品面は背面へ、USB は左辺 |
| J1 / J2 | B | 行 y = 13.86 / 31.64、x = 2.12–50.38 | どちらも1番ピンが USB 側（左） |
| B0070 | B | (54.75, 1.75)–(85.25, 32.25) | レンズは背面へ、中心 (70.01, 14.40)。ヘッダが下辺 |
| J4 | B | 行 y = 30.98（奇数）/ 28.44（偶数）、x = 81.44–58.58 | 1番ピンが右端 |
| H1–H3 | - | (14, 4.4)、(72, 4.4)、(14, 27.4) | HAT の取付穴と同軸。M2.5 x 11 mm のスペーサーで HAT を支える |

- HAT の4つ目の取付穴 (72, 27.4) は、背面のカメラ用ソケットとねじ頭が重なるので、キャリアには穴を開けません。その角は前カバーの柱で押さえます。
- H1–H3 のねじ頭（Ø4.5）は Pico とカメラの下に入ります。どちらもソケットとヘッダ樹脂の分（11 mm）浮くので当たりませんが、Pico・カメラを差す前に締めます。H3 のねじ頭と J2 のソケットの隙間は 0.7 mm です。
- Pico の SWD コネクタは右端でカメラと 3 mm しか離れていません。SWD を使うときは、ケースを開けてカメラを抜きます。

## 積み重ね（背面から、推定）

| z (mm) | 部品 |
|---|---|
| 0–2.4 | 背面ケース |
| 3.0–6.5 | カメラのレンズ（Pico の USB・SWD は 2.9 mm で、これより低い） |
| 6.5–8.1 | カメラ基板 |
| 8.1–19.1 | カメラのヘッダ樹脂 2.5 + ソケット 8.5 |
| 19.1–20.7 | キャリア基板 |
| 20.7–31.7 | J3 の樹脂 2.5 + HAT のソケット 8.5 |
| 31.7–33.3 | HAT 基板 |
| 33.3–35.8 | LCD モジュール（要実測） |
| 36.1–38.5 | 前カバー |

ケースの外形は約 **91.4 x 39.4 x 38.5 mm** になる見込みです。J1・J2・J4 を高さ 5 mm 前後の低背ソケットにすれば、約 35 mm まで薄くなります。厚さの大半は2段のソケットで、HAT 側の 11 mm は Raspberry Pi の HAT の規格どおりなので削れません。

## 実物で測る項目

HAT の寸法図は公開されていません（Waveshare が出しているのは外形 65 x 30.2 mm だけ）。取付穴とヘッダの位置は Raspberry Pi Zero と同じ配置（穴は縁から 3.5 mm、間隔 58 x 23 mm、ヘッダ中心は上辺から 3.5 mm）と仮定しています。

| 項目 | 現在の仮定 | 使い道 |
|---|---|---|
| 取付穴の位置と径 | Pi Zero と同じ、M2.5 | H1–H3、スペーサー |
| ヘッダの位置と1番ピン | 中心が左から 32.5、上から 3.5 | J3 |
| ソケットの高さ | 8.5 mm | 厚さ |
| HAT 基板の厚さ、LCD の厚さ | 1.6 / 2.5 mm | 厚さ、前カバー |
| LCD の表示域の位置 | 未定 | 前カバーの窓 |
| ジョイスティックの中心と高さ、KEY1–3 の中心と高さ | 未定 | 前カバーの穴、キャップ |
| HAT 裏面の部品の高さ | 未定 | J3 周りとの干渉 |

## 次の作業

1. 上の項目を実物で測り、`generate.py` の定数を直す。
2. KiCad でフットプリントを機械領域に合わせて配置し、配線する。J1/J2/J4 は B 面配置でピン配列が反転する。
3. Rev D の `3dprint/` をもとにケースを生成する。
4. コネクタ実装込みで基板を発注する見積もりを取る。低背ソケットを選べるかもここで確かめる。

## 確認

KiCad 10.0.7 の `kicad-cli` で確かめました。

- 回路図の ERC はエラー0件。警告はフットプリントライブラリが CLI の環境に未登録という5件だけ。
- 書き出したネットリストで、各ネットのピンが上の表と `board_pins.h` に一致する。3V3 は7ピン、GND は19ピン、信号はどれも2ピン。
- PCB は読み込めて、DRC の指摘は固定穴のライブラリ未登録の警告3件だけ。電気フットプリントは未配置なので、配線の検査はまだ。
